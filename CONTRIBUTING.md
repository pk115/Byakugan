# Contributing

Thank you for helping improve Byakugan.

1. Discuss significant changes in an issue before implementation.
2. Keep the project focused on Supabase heartbeat monitoring.
3. Add tests for behavior changes.
4. Run `npm test`, `npm run typecheck`, and `npm run build` before opening a pull request.
5. Never commit credentials, production URLs, database files, or user data.
