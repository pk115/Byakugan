# แผนพัฒนา Threats ทีละเฟส

แต่ละเฟสมี commit และ Docker tag ตาม commit เพื่อทดลองและย้อนกลับได้
ตามคำสั่งล่าสุด พัฒนาเฟส 2–7 ต่อเนื่องโดยแยกคอมมิต แล้วเผยแพร่รุ่นรวมและอัปเดต Docker local

| เฟส | ผลที่เปิดดูได้ | เกณฑ์สำคัญ |
|---|---|---|
| 1 | เมนูภัยคุกคาม: Log ที่ควรตรวจสอบ ตัวกรอง เครื่อง/IP/เวลา รายละเอียดความเสี่ยงและหลักฐาน ไทย/อังกฤษ | ไม่รวม HTTP error ทั่วไป ไม่อ้างว่าเจาะสำเร็จ แบ่งหน้าฝั่ง server ใช้สิทธิ์ Log เดิม |
| 2 | ภาพรวมจำนวนจริงตามช่วงเวลา สรุปราย IP และ Coverage รายเครื่อง | แยกเครื่องไม่ปน แสดงรับ Log ล่าสุด/ไม่ทราบความครบ แยกจำนวนเหตุการณ์กับจำนวนเคส |
| 3 | กฎการยืนยันตัวตนผิดซ้ำแยก IP/เครื่อง/บัญชี และเชื่อมเคสเดิม | ส่งซ้ำไม่เพิ่มเคส รับทราบไม่แจ้งวน เปิดใหม่ตามเงื่อนไขที่ระบุได้ |
| 4 | ตัวเชื่อม NPM/UFW/Fail2ban และคู่มือตั้งค่า Agent | เก็บ IP ผ่าน proxy อย่างถูกต้อง มีหลักฐานการปฏิเสธ/แบน มี test fixtures |
| 5 | GeoIP แผนที่ เส้นเคลื่อนไหว กราฟ และอันดับ | ไม่อ้างตำแหน่งว่าเป็นตัวบุคคล IP ไม่มีพิกัดยังดูในตารางได้ หยุด motion ได้ |
| 6 | ลำดับเหตุการณ์ ตั้งเกณฑ์/ข้อยกเว้น แจ้งเตือนรวมกลุ่ม และ Excel | เชื่อมจากหลักฐาน ระบุความไม่แน่นอน เก็บ audit และส่งออกตามขอบเขตเครื่อง |
| 7 | Suricata EVE และรายละเอียด IDS | ต้องมี sensor ที่เห็น traffic แยกตรวจพบ/บล็อก/ยืนยันผลกระทบ |

## เฟส 1

- ใช้ Log เดิม ไม่มี migration และไม่เปลี่ยนข้อมูลหรือสถานะเคสเดิม
- เหตุการณ์ที่รองรับ: LOGIN_FAILED, SSH_LOGIN_FAILED, SUDO_AUTH_FAILED,
  ROOT_LOGIN_DENIED, VPN_AUTH_FAILED, DB_AUTH_FAILED, FIREWALL_DENY
- เมนูใช้สิทธิ์เดียวกับ Event logs (ADMIN/OPERATOR/AUDITOR)
- โหลดครั้งละ 100 รายการ ตัวเลขในหน้าคือจำนวนที่โหลด ไม่ใช่ยอดรวมทั้งช่วงเวลา
- กดรีเฟรชเพื่อดึงข้อมูล ไม่อ้างว่าเป็น live packet capture
- ไม่พบข้อมูลอาจเกิดจากไม่ได้เปิดส่ง Log, ไม่มีเหตุการณ์ที่รองรับ หรือช่วงเวลาไม่ตรง
- ไม่ต้องติดตั้ง Agent ใหม่สำหรับหน้าเฟส 1 แต่ Agent ต้องส่ง Log ที่รองรับอยู่แล้ว
- ยังไม่รวมแผนที่ การตรวจจับใหม่ การสร้างเคสใหม่ การบล็อก IP และภาพรวม Coverage

## วิธีทดลอง

1. อัปเดต image แล้ว login ด้วย ADMIN/OPERATOR/AUDITOR เปิดเมนูภัยคุกคาม
2. เลือกเครื่องและช่วงเวลาที่มี Log ล็อกอินผิดหรือ Firewall deny
3. ตรวจ IP/บัญชี/เวลาเทียบกับ Event logs และเปิดรายละเอียดหลักฐาน
4. สลับไทย/อังกฤษ ตรวจข้อความและปี ค.ศ. ในเขตเวลาที่ตั้งไว้
5. ทดลองเครื่องที่ไม่มีข้อมูล ต้องแสดงสถานะว่าง ไม่อ้างว่าปลอดภัย

ทดสอบข้อมูลจำลองในฐานข้อมูลชั่วคราวเท่านั้น ไม่สร้างการโจมตีบน production

## สถานะรุ่นรวมเฟส 2–7

พัฒนา Overview, Coverage, เคส, ตัวเชื่อม NPM/UFW/Fail2ban, แผนที่ GeoIP, กราฟ, กฎ/ข้อยกเว้น,
ลำดับหลักฐาน, แจ้งเตือนรวมกลุ่ม, Excel และตัวอ่าน Suricata EVE แล้ว
คู่มือตั้งค่า: [threat-connectors-th.md](threat-connectors-th.md)

การติดตั้ง image ไม่ได้เปิดแหล่ง Log ที่ยังไม่ตั้งค่า ต้องอัปเดต Linux Agent และตั้ง path ของแต่ละแหล่ง
Windows Agent เดิมใช้ Security logs ที่รองรับอยู่แล้ว แต่ยังไม่เก็บ Windows Firewall/Defender เพิ่ม
GeoIP ต้องมีฐานข้อมูล และตำแหน่ง server ต้องตั้งโดยผู้ดูแล ไม่สมมุติพิกัดให้เครื่องจริง
ไม่มีการบล็อก IP อัตโนมัติหรือการติดตั้ง Suricata sensor บน production ในงานนี้
